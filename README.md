## Project Description

A Vue.js-based student management system built with VS Code. This application manages student records including enrollment, grades, and performance tracking.

**Module 6 Entity Selected:** Student (with attributes: ID, Name, Email, Phone, GPA, Enrollment Date)

## Implemented Features

- ✅ Add new student records
- ✅ View all students in table format
- ✅ Edit student information
- ✅ Delete student records
- ✅ Search/filter students by name or ID
- ✅ Calculate GPA averages
- ✅ Data persistence using localStorage
- ✅ Form validation
- ✅ Responsive UI design

## Technologies Used

- **Frontend:** Vue.js 3
- **Styling:** CSS3 / Bootstrap
- **Storage:** localStorage API
- **IDE:** VS Code
- **Language:** JavaScript

## Installation & Run Instructions

```bash
# Install Vue CLI
npm install -g @vue/cli

# Create project
vue create student-management

# Navigate to project
cd student-management

# Install dependencies
npm install

# Run development server
npm run serve

# Build for production
npm run build
